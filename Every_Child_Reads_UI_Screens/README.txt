This directory contains high-resolution presentation screenshots and documentation
for the "Every Child Reads" AI Reading Assessment frontend prototype.

--------------------------------------------------------------------------------

   - Side-by-side: Reference Text (ఆదర్శ పాఠం) vs. Recognized Speech Text

5. 05_Teacher_Dashboard.png

   - Categorized common reading difficulties with classroom intervention plans
   - Filterable student assessment records registry

6. All_Screens_Overview.png
