An Education Technology Innovation by SHR Trinity
Every Child Heard. Every Reader Empowered.
=============================================================================

This folder contains the high-resolution PNG screenshots for all 5 UI screens
of the AksharaMitra (అక్షరమిత్ర) AI-Powered Bilingual Reading Intelligence
and Personalized Learning Platform:

1. 01_Student_Dashboard.png
   - Student Profile Hero, Grade Selector (Classes 1–10), Language Toggle
     (Telugu / English), Difficulty Tier Selection, and Passage Preview.

2. 02_Reading_Assessment.png
   - Large child-friendly Telugu/English passage display, interactive
     microphone recording console, timer, and progress tracker.

3. 03_Reading_Analysis.png
   - Color-coded word-level diagnostics (Green: Correct, Red: Mispronounced,
     Orange: Skipped, Blue: Repeated), Reference vs. Recognized Speech, and
     Phonological Observations.

4. 04_Assessment_Results.png
   - AksharaMitra Evaluation Report Scorecard (Overall Proficiency, Accuracy %,
     Pronunciation, Fluency, WPM, Word Breakdown, Benchmarks, and Practice Plan).

5. 05_Teacher_Dashboard.png
   - Executive School KPIs, Telugu vs. English Comparison, Grade-Wise Analytics
     (Classes 1–10), Common Reading Difficulties, and Longitudinal Student Tracking.

6. All_Screens_Overview.png
   - Combined 5-screen composite overview.
